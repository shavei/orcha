# אורחה (Orcha) website

A one-page website for **אורחה**, the camping and hiking store at Hillel 31, Jerusalem (since 1978).

Plain HTML/CSS/JS with no build step. Open `index.html` in a browser, or serve the folder with any static host (GitHub Pages, Netlify, Vercel).

```
index.html        page content (Hebrew, RTL)
styles.css        styles
script.js         mobile menu, live "open now" status (Jerusalem time), scroll reveal
assets/           favicon
```
